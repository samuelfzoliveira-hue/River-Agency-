# Casa Bar Matriz — Apresentação da identidade visual

Landing page estática (HTML + CSS + JS, sem build) que apresenta a identidade visual do PDF:
conceito, paleta, logotipo e variações, monograma, tipografia, elementos gráficos e aplicações.
Abra `index.html` ou publique a pasta em qualquer hospedagem estática.

Cores `#061c2c`, `#e8600a`, `#792608`, `#fef8eb`. Fontes: DM Serif Display, Roboto Slab, Barlow Condensed (em `assets/fonts`).
